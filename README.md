## 背景
电信诈骗是指犯罪分子通过电话、短信、网络等通信手段，编造虚假信息、设置骗局，对受害人实施远程、非接触式诈骗，从而骗取财物或隐私信息的违法犯罪行为。

常见诈骗类型（公安部公布的高发类型）

• 刷单返利：发案率和受骗人数最多。
• 虚假网络投资理财：单笔涉案金额最大（俗称“杀猪盘”）。
• 虚假购物、服务类：发案量居第三位。
• 冒充电商物流客服：以退款、关闭自动扣费等理由诱导点击链接。
• 虚假贷款、征信类：以“无抵押、低利率、注销校园贷”为诱饵。
• 冒充领导、熟人：伪造头像和身份要求转账或垫资。
• 冒充公检法及政府机关：声称涉嫌违法要求汇入“安全账户”。
• 网络婚恋交友、假恋人：通过暧昧关系诱导参与虚假投资。

常用作案手法与技术特征

• 改号与转接：利用VoIP、非法信号转接设备，将境外或异地电话伪装成“本地号码”降低防备。
• 屏幕共享与木马：诱导受害者下载远程控制软件或恶意链接，实时监控屏幕并直接转走资金。
• AI与深度伪造：利用AI语音或视频冒充亲友、领导实施精准诈骗。
